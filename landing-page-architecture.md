# Landing Page Architecture (8-Section Framework)

A structural checklist for designing or auditing high-converting landing pages. Use it to identify which sections are present, missing, or weak.

---

## 1. Hero
**Structure:** Eyebrow → Headline → Subheadline → CTA → Trust Signals
**Job:** Earn 5 seconds of attention or lose the visitor to scroll/bounce.
**Concrete requirements:**
- Eyebrow: 3–6 words, category or credibility tag (e.g. "For Series A Founders")
- Headline: outcome-focused, ≤10 words, no jargon (e.g. "Cut Deploy Time by 80%")
- Subheadline: 1 sentence explaining *how* the outcome happens
- CTA: verb-first button text ("Start Free Trial", not "Submit")
- Trust signals: logos, star rating, or user count — visible without scrolling

## 2. Success State (conditional — post-signup/purchase pages only)
**Structure:** Checkmark/confirmation icon → Confirmation message → Deliverable list
**Job:** Kill buyer's remorse in the first 3 seconds after conversion.
**Concrete requirements:**
- Confirmation restates exactly what the user gets ("You're in — check your inbox for X")
- Deliverable list: 3–5 bullet items, no ambiguity about next steps

## 3. Problem–Agitate
**Structure:** 3 specific problems + agitation → Personal transition line
**Job:** Make the status quo feel costly enough to justify acting now.
**Concrete requirements:**
- Each problem is a specific, named pain (not "you struggle with productivity" — instead "you spend 6 hours/week on manual QA")
- Agitation = quantify the cost (time, money, risk) of each problem
- Transition line bridges to the solution in 1 sentence ("That's why we built X")

## 4. Value Stack
**Structure:** 4 descending-value tiers → Total value sum → Actual price
**Job:** Make declining the offer feel like a bad trade.
**Concrete requirements:**
- Each tier lists a deliverable + its standalone dollar value
- Tiers ordered highest → lowest value
- Show "Total Value: $X" struck through against "Your Price: $Y"

## 5. Social Proof
**Structure:** Section header → 3 testimonials, each with a specific measurable result
**Job:** Let a third party do the persuading.
**Concrete requirements:**
- Each testimonial includes a number ("reduced churn 22% in 60 days"), not vague praise
- Include name, title/company, and photo — anonymous quotes lose most of their weight

## 6. Transformation
**Structure:** 4 stages — Quick Win → Compounding Result → Competitive Advantage → 10x Outcome
**Job:** Make the future state visible and specific, not aspirational fluff.
**Concrete requirements:**
- Quick Win: what happens in week 1
- Compound: what happens by month 1–3
- Advantage: how this outperforms the status quo/competitor
- 10x: the best-case long-term outcome, stated as a number or milestone

## 7. Secondary CTA
**Structure:** Avatar stack (recent users) → Question-form headline → Low-friction "Yes" button
**Job:** Convert scrollers who skipped the hero CTA.
**Concrete requirements:**
- Avatar stack: 5–8 small profile photos, "Join 1,200+ users" style caption
- Headline poses a yes/no question the visitor will answer "yes" to internally
- Button text should feel like agreement, not a form submission ("Yes, Show Me How")

## 8. Footer
**Structure:** Logo → Navigation → Social/legal links
**Job:** Establish legitimacy and provide required links (privacy, terms, contact).
**Concrete requirements:**
- Nav limited to core pages (Pricing, About, Contact, Docs) — not a full sitemap
- Include legal links (Privacy Policy, Terms) for compliance and trust
- Social icons only if the accounts are active — dead links hurt credibility more than omission

---

## Audit Checklist
When reviewing an existing page, check off each section:
- [ ] Hero passes the 5-second test
- [ ] Problem-Agitate uses specific, quantified pain points
- [ ] Value Stack shows a real price anchor
- [ ] Social proof includes measurable results, not adjectives
- [ ] Transformation section has 4 distinct, escalating stages
- [ ] Secondary CTA exists for scroll-and-skip visitors
- [ ] Footer has required legal/trust links
